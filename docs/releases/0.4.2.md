# ZebTrace 0.4.2 · Local recording review / 本地录音回顾

Preview · build 9 · 2026-09-07

## English

This release adds local transcription and summaries to the earlier v0.2.0 recording-only app. **Open Main Window** in the menu bar now opens a recording library: choose a recording by date, search its date or summary, read the summary/transcript, and listen to the original audio without finding folders manually.

- A native sidebar, simple toolbar, and compact player keep common actions close. Copy, regenerate, file, and deletion actions are available in **More**.
- Speech recognition offers **Whisper large-v3-turbo Q5** (default) and **Whisper large-v3 Q5**. **Qwen3 4B Q4** summarizes the resulting text; a small Silero model helps detect speech for transcription. Model choice persists and applies to future processing.
- **Models and Storage…** manages downloads, model deletion, disk use, and inference memory. Models live in `Models/` inside the chosen recording folder, defaulting to `~/Downloads/ZebTrace/Models`.
- Generated files remain beside each recording. Transcripts can survive a failed summary, and reusable processing caches support retrying interrupted work. Results are checked against their recording before display.
- New recording folders use readable start times, such as `2026-09-07/2026-09-07_09-30-00/`. Earlier folders remain compatible and are not automatically renamed or moved.
- English and Simplified Chinese cover the library, model management, generated-text templates, and app-owned messages. The interface follows the system language by default.

### Install and start

Requires **macOS 14.2+**. The Universal app contains native Apple Silicon and Intel binaries, with inference helpers included. Users do **not** need Python, Homebrew, FFmpeg, Ollama, Xcode, or an account. Intel inference has not been verified on an Intel Mac.

1. Open the DMG and drag **ZebTrace.app** into Applications. When upgrading, pause/save and quit the old app first; existing recordings stay in place.
2. Open the app. This preview is **not notarized**: if macOS blocks it and you trust the source, first attempt to open it, then use **System Settings → Privacy & Security → Open Anyway**. See [Apple's opening instructions](https://support.apple.com/en-us/102445).
3. Use **Start Recording** and approve microphone/system-audio access when prompted. Recording is always started manually; launch, wake, and model downloads do not start capture.
4. Use **Pause and Save → Open Main Window**, select the recording, and choose **Generate Review**.

First review asks to download the default model combination: **3,072,206,549 bytes, about 3.1 GB**. Full large-v3 is an optional **1.08 GB** speech model; its complete combination is about **3.6 GB**. Shared files are reused. Downloads require internet, support resuming, and check pinned versions and SHA-256 hashes. Audio and generated text stay local. Preparing models currently includes the selected ASR model and the shared text/VAD models; there is no separate ASR-only preparation mode. **Recording needs no model download.**

Transcription and summarization run sequentially, and helpers exit to release their memory. **Summarize After Saving** is optional and off by default. Starting recording, sleep, or quit cancels processing; a failed review does not remove the audio.

### Preview boundaries

The app does not assume a particular setting or activity. Capture saves received audio, including non-speech and quiet periods; speech detection affects only derived transcription. Missing recognized words do not establish silence or an absence of activity.

Transcripts and summaries can be wrong. The full Whisper model is not consistently more accurate than Turbo. Microphone/system labels describe capture sources, not people. There is **no speaker identity recognition, reliable speaker-turn separation, acoustic echo cancellation, or synchronized mixed-track playback**. Conservative possible-duplicate annotations retain both source texts. Music and environmental events are not reliably described. **Qwen3-ASR is not integrated**; Qwen3 4B is the text model.

Use in-app **Cleanup and Uninstall…** when removing managed models and settings. Recordings are kept unless explicitly included. Merely deleting the app in Finder does not remove its data, and the app cannot clear macOS-owned permission history. See [usage and cleanup](https://github.com/cutelizebin/zebtrace/blob/v0.4.2/docs/local-review.md), [validation limits](https://github.com/cutelizebin/zebtrace/blob/v0.4.2/docs/release-readiness.md), and the [proposed audio-understanding design](https://github.com/cutelizebin/zebtrace/blob/v0.4.2/docs/audio-understanding-design.md). The design describes future work, not additional features in this release.

本版在早期 v0.2.0 录音版基础上，加入本地转写、总结和录音资料库。菜单栏点击「**打开主界面**」，即可按日期选择录音、搜索日期或总结、阅读总结与逐字稿、试听原始音轨，无需反复到访达寻找文件。

- 原生侧栏、简洁工具栏和底部播放器集中常用操作；复制、重新生成、文件与删除操作收纳在「更多」菜单。
- 转写可选择 **Whisper large-v3-turbo Q5**（默认）或 **Whisper large-v3 Q5**；**Qwen3 4B Q4** 负责文本总结，小型 Silero 模型辅助检测语音。选择会记住，仅影响后续处理。
- 「模型与存储…」提供下载、删除、磁盘占用与推理内存管理。模型保存在用户所选录音位置的 `Models/` 中，默认是 `~/Downloads/ZebTrace/Models`。
- 逐字稿、总结和处理信息与录音保存在一起。总结失败时已保存的逐字稿仍可阅读，重试可复用已完成缓存；展示前检查结果与录音的对应关系。
- 新录音使用明确的开始时间命名目录，例如 `2026-09-07/2026-09-07_09-30-00/`。旧目录仍可读取，不会自动改名或搬迁。
- 主界面、模型管理、生成文字模板和应用自身提示支持中英文，默认跟随系统语言。

### 安装与开始使用

需要 **macOS 14.2 或更新版本**。Universal 安装包包含 Apple Silicon 与 Intel 原生版本及推理组件。用户**无需安装 Python、Homebrew、FFmpeg、Ollama、Xcode，也不需要账号**。Intel 推理尚未在 Intel Mac 真机验证。

1. 打开 DMG，把 **ZebTrace.app** 拖入“应用程序”。升级前先暂停保存并退出旧版，已有录音保留在原位置。
2. 打开 App。本版**尚未公证**：如被系统阻止，确认来源可信并尝试打开一次后，前往「**系统设置 → 隐私与安全性 → 仍要打开**」。参见 [Apple 官方说明](https://support.apple.com/en-us/102445)。
3. 点击「开始记录」，按提示授权麦克风和系统音频。录音始终手动开启；启动、唤醒或下载模型都不会自动开始录音。
4. 「暂停并保存」后打开主界面，选择录音并点击「转写并总结」。

首次回顾需确认下载默认组合，共 **3,072,206,549 字节，约 3.1 GB**。可选的完整版语音模型约 **1.08 GB**，包含共用模型的完整组合约 **3.6 GB**；已下载的共用文件会复用。下载需要联网，支持续传，并校验固定版本和 SHA-256；音频和生成文字留在本机。当前准备模型会包含所选 ASR 和共用的文本、语音检测模型，还没有仅准备 ASR 的独立模式。**只录音无需下载模型。**

转写和总结依次运行，完成后推理进程退出释放内存。「保存后自动总结」可选且默认关闭。开始录音、睡眠和退出会取消处理，回顾失败不会删除原始音频。

### 预览版边界

录音不预设场景或活动，保存收到的音频，包括非语音和安静时段；语音检测只影响衍生的转写。没有识别到文字，不等于没有声音或活动。

逐字稿和总结都可能出错，完整版 Whisper 也不保证始终优于 Turbo。麦克风/系统声音标识的是采集来源，不是人的身份。本版**没有身份识别、可靠的说话人分段、声学回声消除或双轨同步混音播放**；对可能重复的收音只作保守标注，两路原文均保留。音乐和环境声音事件也还不能可靠识别。**Qwen3-ASR 尚未集成**，Qwen3 4B 是文本模型。

需清理模型和设置时，请使用应用内「清理与卸载…」。录音默认保留，只有明确选择包含录音时才处理。仅在访达删除 App 不会删除其数据，应用也不能清除 macOS 管理的权限历史。详见[中文使用指南](https://github.com/cutelizebin/zebtrace/blob/v0.4.2/docs/quick-start.zh-CN.md)、[验证边界](https://github.com/cutelizebin/zebtrace/blob/v0.4.2/docs/release-readiness.md)和[后续音频理解设计](https://github.com/cutelizebin/zebtrace/blob/v0.4.2/docs/audio-understanding-design.md)。设计文档描述的是后续工作，不代表本版已经支持。
