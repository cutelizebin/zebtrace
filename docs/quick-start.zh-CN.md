# ZebTrace 使用指南

ZebTrace 是一个极简 macOS 菜单栏录音工具，手动控制开始与暂停，分别保存系统声音和麦克风音轨。**[v0.4.2（build 9）预览版](https://github.com/cutelizebin/zebtrace/releases/tag/v0.4.2)** 在早期 v0.2.0 录音版的基础上，新增录音资料库、本地转写与总结、模型与存储管理。

录音不预设场景、用途或活动。用户手动开启录制期间，应用保存两路实际收到的音频，包括非语音声音和安静时段；是否有人说话不会决定是否录制。逐字稿与总结是识别出的语音所衍生的文字，不能代表所有声音或活动。

## 下载安装

运行打包好的应用只需要 **macOS 14.2 或更高版本**，不需要安装 Xcode、Swift、Python、Homebrew、FFmpeg 或 Ollama。安装包已包含本地推理引擎，模型由应用在首次使用时另行下载。Universal 包含 Intel 版本不代表本地推理已通过 Intel 真机验证。

1. **[下载 ZebTrace v0.4.2（Universal DMG）](https://github.com/cutelizebin/zebtrace/releases/download/v0.4.2/ZebTrace-0.4.2-universal-preview-unnotarized.dmg)**。同一个安装包同时包含 Apple Silicon 和 Intel 原生版本；ZIP、校验和与版本说明见 [v0.4.2 发布页](https://github.com/cutelizebin/zebtrace/releases/tag/v0.4.2)。
2. 打开 DMG，把 **ZebTrace.app** 拖入 **Applications（应用程序）**。
3. 从“应用程序”打开 ZebTrace，在顶部菜单栏找到 **Z** 图标。

当前提供未公证预览版。如果首次打开被 macOS 阻止，并且你确认下载来源可信，先尝试打开一次，然后到 **系统设置 → 隐私与安全性 → 仍要打开**，再次确认打开。受管理的 Mac 可能不允许手动放行。详见 [Apple 官方说明](https://support.apple.com/en-us/102445)。后续签名、公证版本会简化首次打开流程。

后续版本可在 [全部发布版本](https://github.com/cutelizebin/zebtrace/releases) 查看。

从 v0.2.0 升级时，先暂停保存并退出 ZebTrace，再替换“应用程序”中的旧版。已有录音保留在原位置，旧目录格式仍可读取。只录音不需要下载模型。

## 语言

默认 **语言 → 跟随系统**：按 macOS 首选语言顺序匹配中文或英文；中文的地区/书写变体使用简体中文，均不匹配时回退到英文。

也可选择 **简体中文** 或 **English**，菜单和状态立即切换并记住选择，录音可以继续。系统权限弹窗及目录选择器的标准按钮遵循 macOS 自身的应用/系统语言规则；系统语言更改后可能需要重启应用。

## 开始录音

1. 在 macOS 顶部菜单栏找到 ZebTrace 图标。
2. 点击「开始记录」，并按系统提示允许麦克风与系统音频访问。
3. 首次检查收音时，可播放一段声音并对麦克风说话，确认菜单中两路都显示「有声音」，随后回放文件验证。日常录制不要求两路都有声音；首次检查建议使用 Mac 内置麦克风和耳机输出。
4. 点击「暂停并保存」，随后点击「打开主界面」，选择录音并在底部播放器切换系统声或麦克风试听。「打开所有记录」仍可在访达中查看文件。

暂停会结束当前会话，再次开始会新建会话。关闭应用后重新打开也不会自动录制。录音只保存在本机。

默认保存到 `~/Downloads/ZebTrace`。菜单显示当前保存位置，点击「选择保存位置…」可通过系统目录选择器更改，重启后仍会记住。录制期间不能更改；暂停后切换，下次录制使用新位置。如果自选目录被删除或磁盘离线，应用会报错要求重新选择，不会偷偷改存到其他地方。启动时只检查当前保存目录中的未完成会话。

新录音目录格式为 `yyyy-MM-dd/yyyy-MM-dd_HH-mm-ss/`，例如 `2026-01-15/2026-01-15_09-30-00/`，采用开始录音时的本地时间和公历。同秒名称已存在时，依次追加 `_02`、`_03`，不会覆盖已有记录。UUID 保留在目录内的 `session.json` 的 `id` 字段中。早期 v0.2.0 使用 `yyyy-MM-dd/HH-mm-ss-<UUID>/`；新版本仍兼容原位恢复这些旧目录，不会自动改名或搬迁。

旧版 MyContext 的自定义保存位置与分段设置会一次性迁移，已有 ZebTrace 设置不会被覆盖。这只迁移设置，应用不会自动搬迁或删除录音。应用标识已更换为 `org.zebtrace.app`，首次录制需要为 ZebTrace 重新授予系统权限。

默认每 10 分钟分段，可从「分段时长」子菜单选择 1、5、10、30、60 分钟；设置会记住，录制期间禁用，暂停修改后在下次录制生效。音频边录边写，不会把整段 10 分钟的 PCM 音频留在内存里；点击「暂停并保存」会封存当前文件，无需等满 10 分钟。分段越长，崩溃时尚未封存的末段可能损失的音频也越多。

系统没有播放声音时，菜单可能显示「等待声音…」，这不会自动停止录制。系统音频权限被拒绝时也可能只有静音，因此需要实际播放声音并回放文件验证。麦克风持续 12 秒没有数据时会自动暂停。蓝牙麦克风启用时可能切换通话模式（HFP），这类格式切换尚未完成真机验证，暂不承诺 AirPods 全兼容。

## 本地转写与总结

1. 从菜单栏点击「打开主界面」，在左侧按日期选择录音。未生成总结时点击「转写并总结」；已有结果可从右上角「更多」菜单重新生成。菜单栏的「录音回顾」仍可直接处理最近录音或选择其他目录。
2. 首次确认「下载并启用」。默认组合为 Whisper large-v3-turbo Q5 转写模型与 Qwen3 4B Q4 总结模型，含小型 Silero 语音检测辅助模型，共 **3,072,206,549 字节，约 3.1 GB**，保存在 `~/Downloads/ZebTrace/Models`，所有录音共用。模型下载需联网；录音和文字不会上传。下载可取消，重试支持断点续传，并校验固定版本与 SHA-256。
3. 在子菜单查看下载/校验、转写和总结进度，或点击「取消处理」。两个模型依次运行，完成后退出推理进程释放资源。
4. 完成后直接在主界面切换「总结 / 逐字稿」。底部播放器可以试听、拖动进度，并从音轨菜单选择麦克风或系统声音；多片段录音才会显示片段选择。复制文字、打开文件夹和删除在右上角「更多」菜单中。左下角「设置」集中提供模型、存储和自动总结入口，不需要通过访达切换录音。

「保存后自动总结」**默认关闭**，模型准备好后才可手动开启。开启后，仅成功的手动「暂停并保存」触发处理；开始录音会先停止分析，睡眠和退出也会取消，退出会等待处理组件结束。取消后不会自动续跑，可稍后从菜单手动重试并复用已保存缓存。分析失败不影响录音；如果逐字稿已保存，仍可从「查看已保存逐字稿…」打开。

语音识别按约 20 秒的短窗自动检测语言，并在转写阶段用语音检测筛选可能含语音的部分；这不控制录制，也不删除原始音轨中的非语音声音。未识别到文字不等于没有声音或活动，当前回顾功能还不能可靠识别音乐或环境声音事件。总结只依据识别出的文字，不推断录音场景，按任务开始时的界面语言输出中文或英文。底层推理、下载的部分诊断可能仍为英文。双轨文字按录音时间排列，只对时间重叠且规范化后完全相同的长句标注「可能重复收音」，保留两路原文；这不是可靠的说话人分段，不会消除回声或自动识别具体发言人，也不会把两个音轨分别当成两个人。模型仍可能识别错误或生成不实总结，当前没有客观准确率结论，请结合逐字稿与音频核对。

结果与音频放在同一会话目录：`transcript.md`、`transcript.json`、`summary.md`、`analysis.json`；可复用缓存放在隐藏的 `.zebtrace-analysis` 中。模型管理入口可移除下载的模型，保留录音和结果；删除当前组合必需的模型会关闭自动总结。可在「模型与存储…」的转写模型下拉框选择 Turbo 或完整版 large-v3 Q5，选择会记住；完整版约 1.08 GB，使用相同的内置推理引擎。完整版组合共约 3.6 GB，已准备好的总结与语音检测文件会复用。准备模型会下载所选 ASR 和共用的总结、语音检测模型；目前还没有只下载 ASR 的独立模式。切换后需要手动重新生成已有录音。不同录音的效果各有差异，完整版不保证全面更准。暂不支持任意模型导入。**Qwen3 4B 是文本总结模型，Qwen3-ASR 尚未集成。** 更多边界见[本地回顾说明](local-review.md)；说话人分离与跨音轨关联目前是[后续设计](audio-understanding-design.md)，不是此版本已实现功能。

## 清理与卸载

在主界面的「设置」中打开「存储与设置」及「清理与卸载…」，可清理受管理的模型与设置，并将应用移到废纸篓。录音默认保留，勾选包含录音时才会一并处理录音和生成内容。未知用户文件会保留；不可用的外部磁盘需要重新连接。移到废纸篓后需清空废纸篓才能回收相应空间。

仅在访达删除 App 不会自动清理录音目录或模型；macOS 管理的权限记录也不由 App 清除。

## 从源码构建（开发者）

需要 Xcode 15.1+ 或配套的 Swift 5.9+ / macOS 14.2+ SDK，以及 CMake（例如 `brew install cmake`）。首次应用构建会联网下载固定提交、校验哈希的推理引擎源码，再构建随包组件；不会下载模型权重。获取源码后执行：

```sh
git clone https://github.com/cutelizebin/zebtrace.git
cd zebtrace
make run        # 构建并启动本地应用
make check      # 自动测试与应用检查
make package    # 生成 Universal 预览 DMG、ZIP 和校验和
```

如需将源码构建的版本安装到用户应用目录，先退出应用，再执行 `make install`，然后打开 `~/Applications/ZebTrace.app`。普通用户直接下载安装包即可。
